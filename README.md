# Spam Detection & Email Summarizer

#Overview
A Hybrid NLP project that combines:

- Spam Detection using TF-IDF and Logistic Regression
- Email Summarization using Google Gemini AI

#Features
- Detect Spam Messages
- Show Spam Probability
- Summarize Legitimate Emails
- Interactive Streamlit UI

#Technologies Used
- Python
- Streamlit
- Scikit-Learn
- TF-IDF
- Logistic Regression
- Google Gemini API

#Run

pip install -r requirements.txt

streamlit run app.py
